# v9.4 LIVE — คู่มือเทรดมือ

indicator ตัวนี้ **ไม่ส่งออเดอร์เอง** มันบอกว่าเข้าตรงไหน SL ตรงไหน TP ตรงไหน
และควรใช้ lot เท่าไร แล้วคุณไปกรอกในโปรแกรมเทรดเอง

เงื่อนไขเข้าไม้และสูตร TP/SL **เหมือน v9.3 ที่ผ่านการทดสอบมาแล้วทุกบรรทัด**
ไม่มีฟีเจอร์ไหนที่ไม่เคยผ่าน backtest

## ต่างจาก backtest จุดเดียว และเป็นความตั้งใจ

`MTF ไม่ repaint` **เปิดเป็นค่า default**

ตอนรัน backtest บนแท่งย้อนหลัง TradingView ส่งค่า HTF ที่ปิดแล้วอยู่แล้ว
แต่ตอนรันสด มันจะส่งค่าแท่ง HTF ที่กำลังก่อตัว = สัญญาณโผล่แล้วหายระหว่างแท่ง
สวิตช์นี้บังคับให้ live ใช้ค่าแท่งที่ปิดแล้วเหมือน backtest

**อย่าปิดสวิตช์นี้ตอนเทรดจริง** ตารางจะขึ้น `⚠ ยังไม่กัน` เตือนถ้าปิด

## ตั้งค่าตามบัญชีของคุณก่อน

กลุ่ม `1. บัญชีและความเสี่ยง` — สามค่านี้ต้องตรงกับโบรก ไม่งั้น lot ที่บอกจะผิด

| ช่อง | บัญชีมาตรฐาน | micro | cent |
|---|---|---|---|
| 1 lot = กี่ oz | 100 | 10 | 1 |
| lot เล็กสุดที่โบรกรับ | 0.01 | 0.01 | 0.01 |
| ขั้นการเพิ่ม lot | 0.01 | 0.01 | 0.01 |

**ไปถามโบรกก่อนว่าเป็นแบบไหน** ถ้าใส่ผิดตัวเลขความเสี่ยงจะผิดทั้งหมด

## วิธีอ่านป้ายสัญญาณ

```
BUY LIMIT
เข้า 4634.75
TP  4643.62   +$8.88
SL  4625.87   -$8.88
Lot 0.01      เสี่ยง 29.6%
ยกเลิกถ้าไม่ติดใน 6 แท่ง
```

- **เข้า** = ราคาที่วาง Buy Limit
- **Lot** = ขนาดที่ควรใช้ คำนวณจากทุนกับ % ที่ตั้งไว้
- **เสี่ยง %** = ถ้าเกินที่ตั้งไว้มาก แปลว่าต้องใช้ lot ขั้นต่ำเพราะทุนไม่พอ
- **ยกเลิกถ้าไม่ติดใน N แท่ง** = สำคัญ ถ้าเลยแล้วยังไม่ติดให้ลบออเดอร์ทิ้ง

## ขั้นตอนตอนได้สัญญาณ

1. วาง limit ที่ราคา "เข้า" พร้อมตั้ง **SL และ TP ทันที** อย่าตั้งทีหลัง
2. ใช้ lot ตามที่ป้ายบอก
3. จับเวลา ถ้าครบ N แท่งแล้วไม่ติด → **ลบออเดอร์** (จะมี alert เตือน)
4. ติดแล้วปล่อยให้ระบบทำงาน ห้ามขยับ SL

> ข้อ 1 สำคัญที่สุด — บั๊กที่ทำให้ v9 ขาดทุนเฉลี่ยเกินเพดาน SL คือช่วงที่
> ออเดอร์ติดแล้วยังไม่มี SL คุ้มครอง เทรดมือก็เจอปัญหาเดียวกันถ้าตั้ง SL ช้า

## ตั้ง Alert

สร้าง alert 1 อัน เงื่อนไข **"Any alert() function call"** จะได้ครบทุกจังหวะ:

- มีสัญญาณใหม่ (พร้อมราคา SL TP lot ครบ)
- ออเดอร์ติดแล้ว (เตือนให้เช็คว่า SL/TP ตั้งครบ)
- limit ไม่ติดตามเวลา → ให้ไปลบออเดอร์
- ถึง TP / โดน SL

## ค่าที่ควรใช้

**ถ้าเล่น H1** (ชุดที่ผ่านการทดสอบ 20 เดือน 568 ไม้ PF 1.241)
```
ยืนยันด้วย TF   H4      ← ห้ามใช้ H1 บนกราฟ H1
TP = SL ×       1.2
SL = ATR ×      1.2
SL สูงสุด        12
Min Score       4
ยกเลิก limit ใน  6 แท่ง
```

**ถ้าเล่น M5** (ยังไม่ผ่าน — ใช้เก็บข้อมูล demo)
```
ยืนยันด้วย TF   H1
TP = SL ×       1.2
ที่เหลือเหมือนกัน
```

> `TP = SL ×` ตั้ง 1.2 เพราะเทรดมือด้วย lot เดียวแบ่งครึ่งไม่ได้
> จากข้อมูล H1 568 ไม้: 77% ของไม้แตะ 1R ได้ แต่มีแค่ 26% ที่ถึง 1.8R
> เป้าไกลกว่านี้ทำให้ระบบขาดทุน

## สิ่งที่ยังไม่รู้ และ demo มีไว้ตอบ

1. **live ตรงกับ backtest มั้ย** — spread จริง การ slippage การที่คุณกดช้า
2. **M5 มีขอบจริงมั้ย** — ตอนนี้มีแค่ 36 ไม้ ต้องการ ~100 ไม้ขึ้นไป
3. **คุณทำตามระบบได้จริงมั้ย** — ข้อนี้ยากที่สุด และ demo ตอบได้ตรงที่สุด
