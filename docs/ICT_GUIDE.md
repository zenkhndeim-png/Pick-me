# v9.5 ICT — เพิ่มระบบเข้าไม้แบบ ICT

ไฟล์: [`src/XAUUSD_SMC_Pro_v9_5_ICT.pine`](../src/XAUUSD_SMC_Pro_v9_5_ICT.pine)
โค้ดสำหรับคัดลอก: [`CODE_v9_5_ICT.md`](CODE_v9_5_ICT.md)

v9.5 = v9.4 LIVE ทุกบรรทัด **บวก** ระบบสัญญาณตัวที่สองที่เข้าไม้ตามลำดับของ ICT
ส่วนคิด lot / เตือนทุนไม่พอ / ติดตามสถานะ limit / alert ยังเป็นชุดเดิมที่ใช้ร่วมกัน

---

## ⚠️ อ่านก่อน — สถานะการพิสูจน์ของสองระบบไม่เท่ากัน

| ระบบ | สถานะ |
|---|---|
| SMC (ของเดิม) | ผ่าน backtest H1 20 เดือน 568 records PF 1.241 (หักต้นทุนแล้ว) |
| **ICT (ของใหม่)** | **ยังไม่ผ่าน backtest — เป็นตรรกะที่เขียนตามตำรา แต่ไม่มีตัวเลขยืนยันบนทอง** |

ค่า default ของ `ระบบที่ใช้ยิงสัญญาณ` คือ **"ทั้งคู่ — อันไหนมาก่อนก็เข้า"**
ถ้าจะเทรดเงินจริงด้วยชุดที่พิสูจน์แล้วเท่านั้น ให้เปลี่ยนเป็น
**"SMC เท่านั้น (= v9.4 ที่ผ่าน backtest)"** แล้วมันจะให้ผลเท่ากับ v9.4 เป๊ะ ๆ

ทั้งสองระบบใช้ช่องสถานะไม้ร่วมกัน = **ถือได้ทีละไม้เท่านั้น** ไม่มีทางเปิดซ้อน

## ลำดับที่ ICT ใช้ตัดสินใจ (ทำครบ 6 ขั้นถึงจะยิง)

### 1. Liquidity sweep — ราคาไปเก็บ stop คนอื่นก่อน

ระบบจำ short-term high / low ล่าสุด (pivot ความยาว `ictPivLen` ค่าเริ่ม 3)
นั่นคือจุดที่ stop loss ของรายย่อยกองอยู่

```
Bullish setup : low ทะลุลงใต้ swing low เดิม  แต่ close กลับขึ้นเหนือมันได้
Bearish setup : high ทะลุขึ้นเหนือ swing high เดิม แต่ close กลับลงใต้มันได้
```

แค่ทะลุไม่พอ **ต้องปิดกลับ** ไม่งั้นคือเบรกจริง ไม่ใช่การกวาด
บนกราฟจะขึ้นป้ายเหลือง `✕ SSL` / `✕ BSL` ตรงแท่งที่กวาด

จุดที่กวาดไปแล้วจะถูกจำไว้ (`bTaken`) ไม่ยิงซ้ำที่ระดับเดิมอีก

### 2. MSS — พลิกโครงสร้างสวนทางที่กวาดไป

หลังกวาดแล้วต้องปิดทะลุ high/low ระยะสั้น (`ictMssLook` ค่าเริ่ม 10 แท่ง)
ไปทางตรงข้าม **ภายใน `ictArmAge` แท่ง** (ค่าเริ่ม 12) ไม่งั้นทิ้ง setup

ถ้าเปิด `แท่ง MSS ต้องเป็น displacement` แท่งที่เบรกต้องมีตัวเทียนใหญ่กว่า
`ictDspAtr × ATR` (ค่าเริ่ม 0.5) — กันการคลานข้ามเส้นแบบไม่มีแรง

setup จะถูกยกเลิกทันทีถ้าราคา **ปิดต่ำกว่าจุดที่กวาด** (สำหรับฝั่ง buy) = อ่านผิด

### 3. โซนเข้า — FVG ก่อน ถ้าไม่มีค่อย Order Block

ย้อนดูขาที่พลิก (`ictZoneScan` ค่าเริ่ม 12 แท่ง) หาช่องว่างราคา 3 แท่ง
`low[i] > high[i+2]` = FVG ขาขึ้น เอาอันที่ใหม่ที่สุด
ไม่เจอ FVG และเปิด `ictUseOB` → ใช้แท่งลงตัวสุดท้ายก่อนขาขึ้นเป็น Order Block

โซนที่เลือกจะวาดเป็นกล่องบนกราฟ และป้ายจะบอกว่าเป็น `ICT FVG` หรือ `ICT OB`

### 4. Premium / Discount — ห้ามซื้อของแพง

วัดจากกรอบราคา `ictDrLook` แท่งย้อนหลัง (ค่าเริ่ม 40) ไม่ใช่ขา MSS สั้น ๆ

> **จุดที่พลาดง่ายมาก** ถ้าวัดจากขา MSS อย่างเดียว FVG ที่เกิดจาก displacement
> จะอยู่ครึ่งบนของขานั้นเสมอ = ติด premium ทุกครั้ง = ไม่มีสัญญาณออกมาเลย
> ต้องวัดจากกรอบที่ครอบ "ขาที่ลงมากวาด" ด้วย ตัวเลข 40 จึงต้องไม่ตั้งสั้นเกิน

- Long ต้องวาง limit ที่ **ต่ำกว่าครึ่งกรอบ** (discount)
- Short ต้องวางที่ **สูงกว่าครึ่งกรอบ** (premium)

เปิด `ictNeedOTE` เพิ่มได้ถ้าอยากเข้มขึ้น — บังคับให้ราคาเข้าอยู่ในโซนย่อ 62–79%
ของกรอบเดียวกัน (สัญญาณจะน้อยลงมาก)

### 5. Killzone — เข้าเฉพาะเวลาที่เงินใหญ่ทำงาน

อ้างอิงเวลานิวยอร์ก (ระบบจัดการ DST ให้เอง)

| ช่วง | ค่าเริ่มต้น | เปิดไว้มั้ย |
|---|---|---|
| London | 02:00–05:00 | เปิด |
| New York AM | 07:00–10:00 | เปิด |
| PM / London Close | 13:00–16:00 | ปิด |

นอกเวลานี้ **ICT ไม่เข้า** (ฝั่ง SMC ไม่โดนกฎนี้) พื้นหลังจะระบายสีน้ำเงินจาง
ตอนอยู่ใน killzone และตารางจะบอกว่าอยู่ช่วงไหน

บน TF รายวันขึ้นไป session ไม่มีความหมาย → ระบบปล่อยผ่าน ไม่บล็อกทิ้ง

### 6. SL / TP — SL อยู่หลังจุดที่กวาด ไม่ใช่ ATR ลอย ๆ

```
SL (buy)  = จุดต่ำสุดของการกวาด − ictSlBuf × ATR      (ค่าเริ่ม 0.3)
TP        = โหมด "R คงที่"          → entry + SL × rrTP
            โหมด "liquidity ตรงข้าม" → ยอด/ก้นของกรอบ ซึ่งเป็นที่ที่ stop กองอยู่
```

`SL กว้างเกินเพดาน → ข้ามสัญญาณ` เปิดไว้เป็นค่าเริ่มต้น — **ไม่บีบ SL ให้แคบ
กว่าที่โครงสร้างต้องการ** (บทเรียนจากบั๊ก A3 ใน [REVIEW_v9.md](REVIEW_v9.md))
ถ้าไม้ไหน SL เกิน `maxSLusd` ระบบจะข้ามไม้นั้นทิ้ง ไม่ใช่หั่น SL แล้วเข้าอยู่ดี

โหมด liquidity มีตัวกรอง `R ขั้นต่ำ` — ถ้าเป้าใกล้เกินจนได้ R ต่ำกว่าที่ตั้ง จะข้ามไม้

## วางออเดอร์ตรงไหนของโซน

| ตัวเลือก | Buy วางที่ | ผล |
|---|---|---|
| กลางโซน (CE) — ค่าเริ่มต้น | กลางกล่อง | สมดุลระหว่างโอกาสติดกับความกว้าง SL |
| ขอบไกล — รอย่อลึก | ขอบล่างกล่อง | SL แคบสุด แต่บ่อยครั้งราคาไม่ลงมาถึง |
| ขอบใกล้ — เข้าไว | ขอบบนกล่อง | ติดง่ายสุด แต่ SL กว้างสุด |

CE (consequent encroachment) = จุดกึ่งกลาง FVG เป็นค่ามาตรฐานของ ICT

limit ของ ICT ยกเลิกอัตโนมัติถ้าไม่ติดภายใน `ictExpiry` แท่ง (ค่าเริ่ม 8)
และจะมี alert เตือนให้ไปลบออเดอร์ที่ค้าง

## เก็บสถิติก่อนใช้เงินจริง

ตอนนี้ยังตอบไม่ได้ว่า ICT บนทองทำเงินได้จริงมั้ย สิ่งที่ต้องรู้ก่อน:

1. **ICT ยิงกี่ไม้ต่อเดือน** — ถ้าน้อยกว่า 5 ไม้/เดือน ฟิลเตอร์แน่นเกินไป
   ให้ลอง ปิด `ictNeedOTE`, ลด `ictDspAtr`, หรือเพิ่ม `ictZoneScan`
2. **ไม้ ICT เทียบกับไม้ SMC ต่างกันแค่ไหน** — ป้ายบอกที่มาของทุกไม้แล้ว
   จดแยกสองกลุ่ม อย่ารวมกัน
3. **limit ติดกี่ % ** — ถ้าติดต่ำกว่าครึ่ง ให้เปลี่ยนจาก CE เป็น "ขอบใกล้"

ครบ 30 ไม้ของ ICT ค่อยตัดสิน ก่อนหน้านั้นตัวเลขยังไม่มีความหมาย

## เปิดแล้วไม่มีสัญญาณเลย — เช็คตามลำดับนี้

v9.5 มีแถว **"ทำไมยังไม่ยิง"** อยู่ท้ายตารางมุมขวาบน มันจะบอกตัวที่บล็อกอยู่จริง
อ่านแถวนั้นก่อนเสมอ แล้วค่อยมาดูตารางนี้

| แถวบอกว่า | แปลว่า | ทำยังไง |
|---|---|---|
| `ทุนไม่พอ — ต้องมี ≥ $240` | lot ขั้นต่ำของโบรกเสี่ยงเกิน % ที่ตั้งไว้ | ดูหัวข้อถัดไป — **เจอบ่อยที่สุด** |
| `กำลังถือไม้` | มีไม้ค้างอยู่ ระบบถือทีละไม้ | ปกติ รอไม้ปิดหรือ limit หมดอายุ |
| `Sideway — ADX 14.2 < 20` | ADX ต่ำ ระบบไม่เทรด | ปกติ หรือลด `ADX ขั้นต่ำ` |
| `MTF สวนทาง (H1 = DOWN)` | เทรนด์ TF ยืนยันสวนกับทุกฝั่ง | ปกติ |
| `คะแนนได้ 3 / ต้องการ 4` | ฝั่ง SMC ยังไม่ครบเงื่อนไข | ปกติ รอ |
| `นอกเวลา Killzone` | อยู่นอกช่วง London/NY | ปกติ หรือเปิดช่วง PM เพิ่ม |
| `เงื่อนไขครบ — รอแท่งปิด` | ผ่านหมดแล้ว | รอแท่งปิดได้เลย |

### กรณี "ทุนไม่พอ" — คณิตศาสตร์ที่ทำให้ไม่มีสัญญาณสักไม้

สมมติทุน $30 · เสี่ยง 5% · บัญชีมาตรฐาน (1 lot = 100 oz) · SL 12 $/oz

```
เงินที่ยอมเสี่ยงต่อไม้ = 30 × 5%          = $1.50
ขาดทุนถ้าใช้ 1 lot เต็ม = 12 × 100 oz      = $1,200
lot ที่ควรใช้           = 1.50 / 1200     = 0.00125
ปัดลงตามขั้น 0.01                          = 0.00   ← ต่ำกว่า lot ขั้นต่ำ
```

`ไม่ยิงสัญญาณถ้าทุนไม่พอ` เปิดอยู่ → **ระบบตัดทิ้งทุกไม้ ไม่มีอะไรขึ้นบนกราฟเลย**
เพราะ 0.01 lot บนบัญชีมาตรฐาน = 1 oz = เสี่ยง $12 = **40% ของทุน $30**

ทุนขั้นต่ำที่ต้องมี = `SL × oz ต่อ lot × lot ขั้นต่ำ ÷ %เสี่ยง` = `12 × 100 × 0.01 ÷ 0.05` = **$240**
ตัวเลขนี้ v9.5 คำนวณให้แล้วในแถว "ถ้าเข้าตอนนี้"

**ทางออก เรียงตามที่แนะนำ**

| วิธี | ผล |
|---|---|
| ใช้บัญชี micro (`1 lot = 10 oz`) | 0.01 lot เสี่ยง $1.20 = **4%** ของทุน ผ่านสบาย |
| ใช้บัญชี cent (`1 lot = 1 oz`) | lot ที่ควรใช้ 0.12 เสี่ยง $1.44 = 5% พอดี |
| เพิ่มทุนเป็น $240+ | บัญชีมาตรฐานเริ่มใช้ได้ที่ 5% |
| ไป TF เล็กลง (M5/M15) | SL แคบลงตาม ATR ทุนขั้นต่ำก็ลดลง |
| ปิด `ไม่ยิงสัญญาณถ้าทุนไม่พอ` | เห็นสัญญาณ **แต่เสี่ยงจริง 40% ต่อไม้ — แพ้ 3 ไม้ติดคือจบ** |

ช่อง `1 lot = กี่ oz` ต้องตรงกับโบรกจริง ๆ **ไปถามโบรกก่อน** ถ้าใส่ผิด
ตัวเลขความเสี่ยงทั้งหมดจะผิดตาม
