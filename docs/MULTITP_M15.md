# Multi-TP M15 — indicator แยกตัวใหม่

ไฟล์: [`src/XAUUSD_MultiTP_M15.pine`](../src/XAUUSD_MultiTP_M15.pine)
โค้ดสำหรับคัดลอก: [`CODE_MULTITP_M15.md`](CODE_MULTITP_M15.md)

**ไม่เกี่ยวกับตระกูล SMC Pro ในโฟลเดอร์เดียวกันเลย** เป็นตัวใหม่ล้วน ทำตามหน้าตา
ในภาพที่ส่งมา สำหรับ **M15**

---

## โครงสร้างระดับราคา — ถอดจากตัวเลขในภาพ

ตัวเลขในภาพต้นทาง:

```
Buy    4576.790
+Buy.1 4574.833
SL     4571.701   (B: 5,089 pts)
TP1    4580.705   (3,915 pts)
TP2    4584.620   (7,830 pts)
TP3    4588.535   (11,745 pts)
TP4    4592.450   (15,660 pts)
TP5    4596.365   (19,575 pts)
```

คำนวณย้อนกลับได้ว่า:

| ระดับ | สูตร | ตรวจกับตัวเลขจริง |
|---|---|---|
| ระยะ 1 ขั้น (step) | — | 3.915 |
| TP1–TP5 | `เข้า + (1,2,3,4,5) × step` | **ห่างเท่ากันเป๊ะทุกขั้น** ✓ |
| SL | `เข้า − 1.30 × step` | 5.089 ÷ 3.915 = 1.30 ✓ |
| ไม้เสริม | `เข้า − 0.50 × step` | 1.957 ÷ 3.915 = 0.50 ✓ |
| หน่วย point | `ระยะ ÷ 0.001` | 3.915 → 3,915 pts ✓ |

point size 0.001 ตรงกับที่เจอตอนแก้บั๊ก FIX 9 ของ v9 — ทองบนโบรกที่แสดง
3 ทศนิยม 1 point เท่ากับ 0.001 ไม่ใช่ 0.01

ในโค้ดนี้ `step = ATR(14) × ตัวคูณ` (ค่าเริ่มต้น 1.0) ซึ่งบน M15 ทองได้ค่าราว
3–4 ใกล้เคียงกับ 3.915 ในภาพพอดี ทุกตัวคูณปรับได้หมด

> **R ที่แท้จริงของแต่ละชั้น** — SL = 1.30 ขั้น ดังนั้น
> TP1 = 0.77R · TP2 = 1.54R · TP3 = 2.31R · TP4 = 3.08R · **TP5 = 3.85R**
> TP5 ไม่ใช่เป้าใกล้ ๆ ตารางในโค้ดจะนับให้ดูว่าจริง ๆ แล้วถึงกี่ %

## ⚠️ สิ่งที่ลอกได้ และลอกไม่ได้

ภาพต้นทางเป็นโพสต์แจก EA ฟรีที่โชว์ไม้ที่ชนะ 1 ไม้ **ตรรกะสัญญาณข้างในเขา
ไม่มีใครเห็น** สิ่งที่ผมทำได้จากภาพเดียวคือ

| ลอกได้ | ลอกไม่ได้ |
|---|---|
| หน้าตา ป้ายราคาเรียงทางขวา | เขาใช้อะไรตัดสินว่าจะเข้าตรงไหน |
| โครงสร้าง TP/SL/ไม้เสริม (ถอดจากเลขได้ครบ) | เขากรองด้วยอะไรบ้าง |
| หน่วย point และการแสดงผล | ผลระยะยาวของเขาเป็นยังไง |
| บรรทัดอ่านเทรนด์ TF ใหญ่ | — |

เครื่องยนต์สัญญาณในไฟล์นี้ผมใช้ **Supertrend พลิกทาง** ซึ่งเป็นตัวที่ให้ลูกศร
Buy/Sell ครั้งละอันแบบในภาพพอดี อธิบายได้ทุกบรรทัด แต่ **ยังไม่ผ่าน backtest
ใด ๆ** — และภาพที่ทะลุ TP5 หนึ่งไม้ ไม่ได้บอกว่ามันทะลุบ่อยแค่ไหน

ตารางมุมขวาบนจึงนับให้เลยว่าตั้งแต่เปิดกราฟมา **ถึง TP แต่ละชั้นกี่ครั้ง จากกี่ไม้
คิดเป็นกี่ %** เลื่อนกราฟย้อนหลังให้ยาว ๆ แล้วดูตัวเลขจริงก่อนตัดสินใจ

## เครื่องยนต์สัญญาณ

```
Supertrend(factor 3.0, ATR 10) พลิกจากลงเป็นขึ้น  →  Buy
Supertrend พลิกจากขึ้นเป็นลง                     →  Sell
```

ตัวกรองที่มีให้

- **เข้าตามเทรนด์ TF ที่ 1 เท่านั้น** (เปิดไว้เป็นค่าเริ่มต้น) — Buy เฉพาะตอน H1
  อยู่เหนือ EMA50 ของมันเอง / Sell เฉพาะตอนอยู่ใต้
- **เว้นระยะสัญญาณขั้นต่ำ** 4 แท่ง กันยิงรัวตอนตลาดสับ

ปิดตัวกรอง TF ใหญ่ได้ถ้าอยากเห็นทุกครั้งที่ Supertrend พลิก

---

## บรรทัด "1H Trend / 4H Trend"

ในภาพต้นทางเลขถูกตัดขอบจนอ่านไม่ครบ ผมนิยามให้ตรงไปตรงมาว่า

```
ค่าที่แสดง = (close ของ TF นั้น − EMA50 ของ TF นั้น) แปลงเป็น point
```

- ติดลบ = ราคาอยู่ใต้ EMA = ขาลง (สีแดง)
- เป็นบวก = ขาขึ้น (สีเขียว)
- ยิ่งห่างจากศูนย์มาก = เทรนด์ยิ่งแรง

ดึงค่าแบบ **ไม่ repaint** (ใช้แท่ง TF ใหญ่ที่ปิดแล้ว) เปิดไว้เป็นค่าเริ่มต้น
อย่าปิดตอนใช้จริง ไม่งั้นเลขจะขยับไปมาระหว่างแท่ง

---

## อ่านหน้าจอ

- **คลาวด์** = ช่องว่างระหว่าง EMA20 กับ EMA50 เขียว = เร็วอยู่บน แดง = เร็วอยู่ล่าง
- **เส้นเทาหนา** = EMA200
- **เส้นบาง ๆ ตามราคา** = Supertrend
- **ป้ายทางขวา** = ระดับของไม้ที่ถืออยู่ TP ที่โดนแล้วจะเปลี่ยนเป็นสีเขียวและมี ✔
- **ตาราง** = สถานะ + ระยะ 1 ขั้นตอนนี้ + เทรนด์ TF ใหญ่ + สถิติว่าถึง TP ไหนกี่ครั้ง

## ค่าที่แนะนำสำหรับ M15 ทอง

```
Supertrend Factor         3.0     ← ลดเป็น 2.5 ถ้าอยากได้สัญญาณถี่ขึ้น
Supertrend ATR            10
เข้าตามเทรนด์ TF ที่ 1      เปิด
เว้นระยะสัญญาณ             4 แท่ง
ระยะ 1 ขั้น = ATR ×        1.0     ← ได้ราว 3-4 ตรงกับภาพต้นทาง
จำนวน TP                  5
SL = ระยะขั้น ×            1.3
ไม้เสริม                   0.5
TF ที่ 1 / TF ที่ 2         60 / 240
```

**ถ้าตารางบอกว่าถึง TP5 ต่ำกว่า 15%** ให้ลดจำนวน TP เหลือ 2–3 ชั้นแล้วเก็บกำไร
ให้ไวขึ้น จะสมจริงกว่าการเล็ง TP5 ทุกไม้

## ตั้ง Alert

สร้าง alert 1 อัน เงื่อนไข **"Any alert() function call"** จะได้ครบ:
สัญญาณใหม่ (พร้อมราคาเข้า / ไม้เสริม / SL / TP1 / TP สุดท้าย / ระยะขั้น),
ถึง TP แต่ละชั้น, และโดน SL

หรือใช้ `alertcondition` แยก `Buy` / `Sell` ก็ได้
