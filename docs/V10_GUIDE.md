**v10 = v9 ต้นฉบับ แก้บั๊กครบ + เพิ่ม ICT** เป็นสายตรงจาก v9
ไม่เกี่ยวกับสาย v9.4 / v9.5 ที่คิด lot จากขนาดทุน (สายนั้นแยกไปคนละทาง)

หน้าตาและวิธีใช้เหมือน v9 ทุกอย่าง — TP1/TP2, สัญญาณ realtime, กล่อง FVG,
ป้าย BOS/CHoCH, ตาราง MTF ห้า TF, เส้นไม้ที่ลากตามกราฟจนกว่าจะโดน, 0.01 lot คงที่
ไม่มีการถามขนาดทุนและไม่มีการบล็อกสัญญาณเพราะทุนไม่พอ

## บั๊กที่แก้ทั้งหมด 12 ข้อ

10 ข้อแรกอธิบายละเอียดใน [`REVIEW_v9.md`](REVIEW_v9.md) — สรุปสั้น

| # | อาการเดิม | v10 |
|---|---|---|
| 1 | MTF repaint (`lookahead_off` ไม่ใช่ "ค่าที่ปิดแล้ว") | `lookahead_on` + ดึงค่า `[1]` |
| 2 | ขอ M15/M30 จากกราฟ H1 = ขอ TF ที่ต่ำกว่ากราฟ | ตัดออกอัตโนมัติ แสดง `n/a` |

| 5 | logic FVG อยู่ใน `if showFVG` — ปิดปุ่ม = logic หาย | แยกคำนวณกับวาด + ให้คะแนนจริง |
| 6 | `RSI OB/OS` เป็นค่าตาย ปรับแล้วไม่มีผล | ผูกให้มีผลจริง |

| 8 | **ATR กว้างเกินเพดาน → หั่น SL แล้วเข้าอยู่ดี** | ข้ามสัญญาณ ไม่บีบ SL |
| 9 | โหมด Limit นับ TP/SL ทั้งที่ออเดอร์อาจไม่เคยติด | pending → ติด → จบ / หมดอายุ |
| 10 | array/เส้นโตไม่จำกัด เกิน 500 แล้ว `set_x2` ไม่มีผล | จำกัดจำนวนที่เก็บ |
| **11** | **เลข point คิดจาก 0.01 ตายตัว** | อ่านจาก `syminfo.mintick` |
| **12** | **เลข $ คิดจาก 100 oz ตายตัว** | ช่อง `1 lot = กี่ oz` |

### #11 และ #12 มาจากไหน

ดูป้ายบน OANDA ที่ราคาแสดง 3 ทศนิยม (4,586.970) แปลว่า 1 point = 0.001
แต่ v9 หารด้วย 0.01 เสมอ

```
SL 12 $/oz  →  v9 บอก  "1200 point"
            →  ที่ถูกคือ 12000 point   (ผิด 10 เท่า)
```

เลข `$` ก็เหมือนกัน v9 คูณ 100 oz ตายตัว บัญชี micro (10 oz) หรือ cent (1 oz)
จะได้ตัวเลขเกินจริง 10–100 เท่า ตอนนี้ตั้งได้ในกลุ่ม `หน่วยที่ใช้แสดงตัวเลขในป้าย`

> เลขราคา (เข้า / TP / SL) ของ v9 **ถูกอยู่แล้ว** สองข้อนี้ผิดเฉพาะ
> ตัวเลขในวงเล็บที่บอก point กับเงิน

### #8 คือข้อที่กระทบเงินมากที่สุด

จากกราฟจริง ATR(14) = 17.09 บน H1

```
v9  : อยากใช้ SL 17.09 × 1.2 = 20.51  แต่เพดาน 12  →  หั่นเหลือ 12 แล้วเข้าไม้
      = SL แค่ 0.70 ATR  →  ป้ายทุกใบบนกราฟจึงมี SL เท่ากันเป๊ะที่ $12
v10 : อยากใช้ 17.09 × 1.5 = 25.63  แต่เพดาน 20  →  ข้ามสัญญาณนั้นไป
```

**v10 จะยิงสัญญาณน้อยลงกว่า v9 พอสมควร นั่นคือผลที่ตั้งใจ** — ไม้ที่หายไปคือไม้ที่
ระบบเองประเมินว่าต้องใช้ SL กว้างกว่าที่ยอมรับได้ ตารางแถว `SL ที่จะใช้` จะขึ้น
`กว้างเกิน → ข้าม` ให้เห็นตอนนั้นเลย

ถ้าอยากได้จำนวนไม้เท่าเดิม ให้เพิ่ม `SL สูงสุด` แทนการปิดสวิตช์ — เพิ่มเพดาน
คือยอมรับความเสี่ยงที่มากขึ้นอย่างรู้ตัว ส่วนการปิดสวิตช์คือยอมให้ SL แคบกว่าจริง

## ระบบ ICT ที่เพิ่มเข้ามา

เลือกได้ที่กลุ่ม `ระบบสัญญาณ` — ค่าเริ่มต้นคือ **ทั้งคู่ (ICT ได้สิทธิ์ก่อน)**
เลือก `SMC เท่านั้น` แล้วได้ v9 ที่แก้บั๊กแล้วล้วน ๆ ไม่มี ICT มาปน

ลำดับที่ ICT ใช้ตัดสินใจ — ต้องครบทั้ง 6 ขั้น

1. **Liquidity sweep** — ราคาแทงใต้ swing low เดิม **แล้วปิดกลับขึ้นเหนือ**
   (แค่ทะลุไม่พอ ต้องปิดกลับ ไม่งั้นคือเบรกจริง) → ป้ายเหลือง `✕ SSL`
2. **MSS + displacement** — ปิดทะลุ high ระยะสั้นกลับขึ้นไปภายใน 12 แท่ง
   และแท่งที่เบรกต้องตัวใหญ่กว่า 0.5 × ATR → ป้ายน้ำเงิน `MSS ↑`
3. **โซนเข้า** — หา FVG ในขาที่พลิก ถ้าไม่มีใช้ Order Block → วาดเป็นกล่อง
4. **Premium / Discount** — Long ต้องอยู่ครึ่งล่างของกรอบ 40 แท่ง
5. **Killzone** — London 02:00–05:00 / NY 07:00–10:00 (เวลานิวยอร์ก)
6. **SL หลังจุดที่กวาด** + 0.3 × ATR — ไม่ใช่ ATR ลอย ๆ

ป้ายจะบอกที่มาของทุกไม้ในวงเล็บเหลี่ยม: `[ICT FVG]` `[ICT OB]` หรือ `[SMC]`
รายละเอียดของโมเดลและค่าแต่ละช่อง อ่านที่ [`ICT_GUIDE.md`](ICT_GUIDE.md)

> **ส่วน ICT ยังไม่ผ่าน backtest** เป็นตรรกะตามตำรา ไม่มีตัวเลขยืนยันบนทอง
> ต่างจากส่วน SMC ที่มีข้อมูลรองรับ เอาไปรันเดโมจดสถิติแยกสองกลุ่มก่อน

## แถว "ทำไมยังไม่ยิง"

อยู่ท้ายตารางมุมขวาบน บอกตัวที่บล็อกอยู่จริงในตอนนั้น เช่น

```
นอกเวลาเทรด (0800-2300)
Sideway — ADX 14.2 < 20
SL กว้างเกินเพดาน $20
เว้นระยะสัญญาณ อีก 7 แท่ง
MTF สวนทาง (H4)
ยังไม่มีโครงสร้าง SMC (รอ BOS/CHoCH)
คะแนนได้ 3 / ต้องการ 5
เงื่อนไขครบ — รอแท่งปิด        ← ขึ้นเขียวเมื่อพร้อม
```

เพิ่มเข้ามาเพราะ v9 เงียบเกินไป — แยกไม่ออกว่า "เงื่อนไขยังไม่ครบ" หรือ
"ตั้งค่าอะไรผิดจนไม่มีทางยิงได้เลย"

## ตั้งค่าก่อนใช้ — สองช่องนี้ต้องตรงกับโบรก

กลุ่ม `หน่วยที่ใช้แสดงตัวเลขในป้าย`

| ช่อง | ดูจากไหน |
|---|---|
| `1 lot = กี่ oz` | บัญชีมาตรฐาน = 100 / micro = 10 / cent = 1 — **ถามโบรก** |
| `ขนาด 1 point` | ปล่อย `อัตโนมัติ` ก่อน ถ้าเลข point ดูผิดค่อยตั้งเอง |

ถ้าราคาทองในกราฟแสดง 2 ทศนิยม (4586.97) → 1 point = 0.01
ถ้าแสดง 3 ทศนิยม (4586.970) → 1 point = 0.001

ช่องพวกนี้กระทบแค่**ตัวเลขที่แสดง** ไม่กระทบเงื่อนไขเข้าไม้เลย

## ค่าที่แนะนำสำหรับ H1

```
ยืนยันด้วย TF          H4      ← สำคัญที่สุด ห้ามใช้ H1 บนกราฟ H1
ระบบสัญญาณ             ทั้งคู่ (ICT ได้สิทธิ์ก่อน)
Min Score              5       (จากเต็ม 8)
บังคับโครงสร้าง SMC     เปิด
SL = ATR ×             1.5
SL สูงสุด               20
SL กว้างเกิน → ข้าม     เปิด
TP1 / TP2              1.0 / 2.0
ระยะห่างสัญญาณ (SMC)    15 แท่ง
ระยะห่างสัญญาณ (ICT)    5 แท่ง
Limit pullback         0.4 × ATR, ยกเลิกใน 6 แท่ง
Session                08:00–23:00 (London)
Killzone               London + New York AM
ADX ขั้นต่ำ             20
```

**M15 / M5** — ลด `SL สูงสุด` เหลือ 8–10, `กรอบวัด P/D` เหลือ 30,
`หลังกวาดแล้วต้อง MSS ภายใน` เหลือ 8, ยืนยันด้วย H1

## ตั้ง Alert

สร้าง alert 1 อัน เงื่อนไข **"Any alert() function call"** ได้ครบทุกสัญญาณ
ทั้ง SMC และ ICT พร้อมตัวเลข entry / TP1 / TP2 / SL / point / $

หรือใช้ `alertcondition` แยกทีละอันก็ได้ — มีให้เลือก 6 อัน รวมสัญญาณเตือน
`ICT — กวาด SSL` / `ICT — กวาด BSL` ที่ยิงตั้งแต่ตอนกวาด liquidity
(ก่อนจะมีสัญญาณเข้าไม้จริง) ไว้เตรียมตัวล่วงหน้า
