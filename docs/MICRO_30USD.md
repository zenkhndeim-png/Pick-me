# เทรดด้วยทุน $30 — คู่มือ v9.3 MICRO

## ปัญหาที่ต้องเข้าใจก่อน

ผลที่ผ่านการทดสอบแล้ว (PF 1.241, DD 14.29%) วัดบน **ทุน $1,000 ขนาด 0.02 lot**

ทุน $30 ที่ **0.01 lot** ซึ่งเป็นขนาดเล็กสุดของโบรกทั่วไป:

| TF | ATR(14) โดยประมาณ | SL ที่ระบบจะใช้ | เสี่ยงต่อไม้ (% ของ $30) |
|---|---|---|---|
| H1 | $10–15 | $12 (ชนเพดาน) | **40%** |
| M15 | $5–7 | $6–8 | **20–28%** |
| M5 | $2.5–3.5 | $3–4 | **10–14%** |
| M1 | $1–1.5 | $1.2–1.8 | **4–6%** |

ระบบนี้แพ้ 50.88% ของ records การแพ้ติดกัน 3 ไม้เป็นเรื่องปกติ

- บน H1 แพ้ 3 ไม้ = **หมดพอร์ต**
- บน M5 แพ้ 3 ไม้ = เหลือ ~$19

**สรุป: H1 กับ M15 เทรดด้วย $30 ไม่ได้ ต้องลงไป M5 เป็นอย่างต่ำ**

## แต่ TF ต่ำมีต้นทุนซ่อนอยู่

spread ทองราว **$0.30 ต่อ oz** ไม่เปลี่ยนตาม TF แต่ SL เล็กลง:

| TF | SL | spread คิดเป็น % ของความเสี่ยง |
|---|---|---|
| H1 | $12 | 2.5% |
| M15 | $7 | 4.3% |
| M5 | $3.5 | **8.6%** |
| M1 | $1.5 | **20%** |

ยิ่งลง TF ต้นทุนยิ่งกินขอบ — บน H1 ต้นทุนกินกำไรไป 18% ($173 จาก $969)
บน M5 จะกินหนักกว่านั้นหลายเท่า **ขอบ PF 1.241 ที่วัดได้บน H1 จะไม่เหลือเท่าเดิมแน่นอน**

นี่คือเหตุผลที่ทุนน้อยเทรดยากกว่าทุนมาก ไม่ใช่เพราะระบบ แต่เป็นคณิตศาสตร์

## สิ่งที่ v9.3 เพิ่มมา

**1. Risk gate — ข้ามไม้ที่เกินกำลังพอร์ตเอง**

```
ความเสี่ยงจริง = ระยะ SL ($/oz) × ขนาดไม้ (oz)
ถ้า เกิน maxRiskPct ของทุน → ไม่เข้าไม้นั้น
```

ถ้ารันบน H1 แล้ว **ไม่มีไม้เข้าเลย นั่นคือคำตอบที่ถูกต้อง ไม่ใช่บั๊ก**
แปลว่า TF นั้น SL ใหญ่เกินทุน

**2. หยุดเทรดทั้งวันเมื่อขาดทุนถึงเพดาน** (default 20% ของทุน = $6)

**3. หยุดเทรดเมื่อแพ้ติดกัน** (default 3 ไม้ นับใหม่ทุกวัน)

**4. ตารางบอกความเสี่ยงทุกไม้** เป็นทั้ง $ และ % — เขียวคือผ่าน แดงคือเกินเพดาน

**5. ปิดครึ่งไม้อัตโนมัติเมื่อขนาดไม้แบ่งไม่ได้** — 1 oz แบ่งครึ่งไม่ได้
ระบบจะข้าม TP1 ไปใช้ TP2 อย่างเดียวเอง

## ค่าที่ตั้งมาให้แล้ว

```
ทุน            $30
ขนาดไม้        1 oz (= 0.01 lot)
เพดานเสี่ยง/ไม้ 10%
เพดานขาดทุน/วัน 20%
แพ้ติดกันหยุด   3 ไม้
commission     0.15 ต่อ contract (spread $0.30/oz)
BE             ปิด (พิสูจน์แล้วว่าขาดทุน)
แก้บั๊ก 1, 2    เปิด
```

**สำคัญ:** แท็บ `คุณสมบัติ` ต้องตั้ง **Initial capital = 30** ให้ตรงกับช่อง "ทุนจริงของคุณ"
ไม่งั้น % drawdown ที่เห็นจะผิด

## ลำดับการทดสอบ

| รอบ | TF | เพดานเสี่ยง | ดูอะไร |
|---|---|---|---|
| 1 | H1 | 10% | คาดว่าไม่มีไม้เข้าเลย — ยืนยันว่า H1 ใหญ่เกินทุน |
| 2 | M15 | 25% | มีไม้เข้ามั้ย PF เท่าไร (เสี่ยง 25%/ไม้ = อันตรายมาก) |
| 3 | **M5** | 12% | **ตัวจริงที่น่าจะใช้ได้** |
| 4 | M1 | 6% | ต้นทุนน่าจะกินขอบหมด |

ดู **Profit Factor** เป็นหลัก ไม่ใช่ Net PnL
ถ้า PF ต่ำกว่า 1.1 ที่ TF ไหน = TF นั้นใช้ไม่ได้

## ทางที่ดีกว่า ถ้าเลือกได้

**บัญชี Cent** — ขนาดสัญญาเล็กลงราว 100 เท่า $30 จะเทียบเท่ามีทุน $3,000
ในเชิงสัดส่วน ใช้ค่า H1 ที่ผ่านการทดสอบมาแล้วทั้งชุด (PF 1.241) ได้เลย
ไม่ต้องลง TF ไม่ต้องรับต้นทุน spread ที่สูงขึ้น

ในสคริปต์ให้ตั้ง `ขนาดไม้ (oz)` = **0.01** แทน 1 แล้วเปิดกราฟ H1 ตามเดิม

> ต้องเช็คกับโบรกก่อนว่าบัญชี cent ของเขารองรับ XAUUSD — บางเจ้ามีแต่คู่เงิน

## ความจริงที่ต้องยอมรับ

จากผลที่ทดสอบได้ ระบบทำ **+79.57% ใน 20 เดือน**

ถ้าผลนั้นเกิดซ้ำได้จริงบนทุน $30 → กำไร **$24 ในเกือบ 2 ปี** หรือราวเดือนละ $1.20
โดยมีโอกาสล้างพอร์ตระหว่างทางสูงมากเพราะเสี่ยงต่อไม้ 10%+ ไม่ใช่ 1–2%

ตัวเลขนี้ไม่ได้บอกว่าห้ามทำ แต่บอกว่า **มูลค่าที่แท้จริงของช่วงนี้คือการเรียนรู้
ไม่ใช่กำไร** ถ้ามองแบบนั้นแล้วยังอยากเดินหน้า ก็เป็นการตัดสินใจที่มีเหตุผล

# ผลที่วัดจริงบน M5 (26 ส.ค. 2026)

XAUUSD OANDA **M5** ช่วง 27 ก.ค. – 26 ส.ค. 2026 (1 เดือน — เพดานข้อมูลของแพ็กฟรี)
ทุน $30 · 1 oz · commission 0.15/contract

| | รอบ 1 | รอบ 2 |
|---|---|---|
| ปิดครึ่งไม้ | แบ่ง 0.5 oz (**บั๊ก**) | ปิดแล้ว — TP2 อย่างเดียว |
| TP2 = SL × | 1.8 | 1.2 |
| Net PnL | −4.39 | **+2.99** |
| Max DD | 9.10 (29.14%) | **6.11 (18.83%)** |
| Profit Factor | 0.77 | **1.202** |
| Win rate | 41.18% | 52.78% |
| จำนวนไม้ | 34 | 36 |

> รอบ 1 มีบั๊ก: `canPartial` ปล่อยให้แบ่งไม้ 1 oz เป็น 0.5 oz ซึ่งโบรกจริงทำไม่ได้
> (ขั้นต่ำ 0.01 lot = 1 oz) แก้ใน commit a9b1ada โดยเพิ่ม input ขนาดเล็กสุดที่โบรกรับ

## ตัวเลขที่สำคัญที่สุด — spread กินขอบ 78%

แกะจากรอบ 2 (36 ไม้ ไม่มีปิดครึ่ง = 1 ไม้ 1 record ต้นทุน $0.30/ไม้):

```
ต้นทุนรวม              36 × $0.30            = $10.80
กำไรขั้นต้นก่อนต้นทุน   17.77 + (19 × 0.30)   = $23.47
ขาดทุนขั้นต้นก่อนต้นทุน  14.78 − (17 × 0.30)   =  $9.68
ขอบจริงก่อนต้นทุน                             = $13.79
```

**PF ก่อนต้นทุน 2.42 → หลังต้นทุน 1.202** ต้นทุนกินขอบไป **78%**

ประมาณการถ้าเปลี่ยนโบรก โดยขอบเท่าเดิม:

| spread ทอง | ต้นทุน/เดือน | กำไรเหลือ | PF |
|---|---|---|---|
| $0.30 (ปัจจุบัน) | $10.80 | $2.99 | 1.20 |
| $0.15 (raw) | $5.40 | $8.39 | ~1.69 |
| $0.10 (raw ดี) | $3.60 | $10.19 | ~1.86 |

**การหาโบรกที่ spread แคบกว่า ให้ผลมากกว่าการจูนพารามิเตอร์ทุกตัวรวมกัน**

## ข้อจำกัดที่ยังแก้ไม่ได้

```
36 ไม้ · 1 เดือน
Win rate 52.78% → ช่วงความเชื่อมั่น 95% = 36.5% ถึง 69%
```

ยังกว้างเกินกว่าจะแยกขอบจริงออกจากความบังเอิญ และรอบ 1 กับรอบ 2 เป็น
**ข้อมูลเดือนเดียวกัน** — บอกได้แค่ว่าตั้งค่าใหม่ชนะตั้งค่าเก่าบนข้อมูลชุดนี้

รอบ 2 เปลี่ยน 2 อย่างพร้อมกัน (แก้บั๊ก + rr2 1.8→1.2) จึงแยกไม่ออกว่าอันไหนช่วย
แต่เหตุผลของ rr2 = 1.2 **มาจากข้อมูล H1 20 เดือน 568 ไม้** ที่พบว่า 77% ของไม้
แตะ 1R ได้ แต่มีแค่ 34% ที่ไปถึง 1.8R — ไม่ใช่การจูนกับข้อมูลเดือนนี้
